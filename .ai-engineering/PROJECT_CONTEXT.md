# PROJECT CONTEXT

## Problema

Muchos restaurantes pequeños gestionan pedidos manualmente.

## Solución

Crear un SaaS para administrar la operación completa.

## Usuarios

- Administrador
- Cajero
- Mesero
- Cocina
- Cliente

## Objetivos

- Automatizar pedidos.
- Reducir errores.
- Escalar a múltiples sucursales.

## Restricciones

- Debe soportar múltiples restaurantes en el futuro.
- Debe poder desplegarse en Docker.
- Debe estar preparado para SaaS Multi Tenant.
