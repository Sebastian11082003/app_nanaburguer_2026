| Campo      | Detalle     |
| ---------- | ----------- |
| **Estado** | ✅ Accepted |

# Contexto

Delivery NO administra repartidores.

Solo:

- registra pedidos delivery,
- pickup,
- direcciones,
- referencias.

---

# Flujo

```text
Delivery User
→ Create Delivery Order
→ Kitchen
→ Cashier
→ Physical Delivery
```
