# ADR-009 — Cloud Deployment Strategy

| Campo                      | Detalle          |
| -------------------------- | ---------------- |
| **Estado**                 | ✅ Accepted      |
| **Cloud Strategy**         | AWS-first        |
| **Alternativas**           | Railway / Vercel |
| **Impacto arquitectónico** | Crítico          |

---

# Contexto

El sistema necesita:

- despliegue cloud,
- alta disponibilidad,
- escalabilidad futura,
- Docker compatibility.

---

# Opciones

## Railway

### Beneficios

- simple,
- rápido,
- barato MVP.

### Problemas

- menor control,
- menos enterprise-ready.

---

## Vercel

### Beneficios

- ideal frontend,
- deployments rápidos.

### Problemas

- backend complejo,
- limitado para APIs complejas.

---

## AWS

### Beneficios

- enterprise-ready,
- escalable,
- múltiples servicios.

### Problemas

- mayor complejidad,
- curva aprendizaje.

---

# Decisión

Se adopta:

# AWS-first Strategy

con:

- Docker deployment,
- PostgreSQL,
- futura escalabilidad.

---

# Arquitectura Futura

```text
CloudFront
→ Load Balancer
→ Backend API
→ PostgreSQL
```

---

# Futuro

- ECS,
- RDS,
- S3,
- Route53,
- Auto Scaling.
