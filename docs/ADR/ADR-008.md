# ADR-008 — REST API + Swagger/OpenAPI

| Campo                      | Detalle         |
| -------------------------- | --------------- |
| **Estado**                 | ✅ Accepted     |
| **Tecnologías**            | Swagger/OpenAPI |
| **Impacto arquitectónico** | Alto            |

---

# Contexto

La API expone:

- auth,
- orders,
- reports,
- payments,
- users,
- delivery.

---

# Problema

¿Cómo documentar la API:

- profesionalmente,
- automáticamente,
- mantenible?

---

# Decisión

Se implementará:

# Swagger/OpenAPI

integrado con NestJS.

---

# Endpoint

```bash
/api/docs
```

---

# Beneficios

| ✅ Beneficios            | ⚠️ Trade-offs   |
| ------------------------ | --------------- |
| Documentación automática | Más decorators  |
| Frontend integration     | DTO maintenance |

---

# Futuro

- SDK generation,
- Postman export,
- API Gateway.
