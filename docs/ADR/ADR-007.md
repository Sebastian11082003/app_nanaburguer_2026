# ADR-007 — Dockerized Development Environment

| Campo                      | Detalle                 |
| -------------------------- | ----------------------- |
| **Estado**                 | ✅ Accepted             |
| **Tecnologías**            | Docker + Docker Compose |
| **Impacto arquitectónico** | Alto                    |

---

# Contexto

El proyecto requiere:

- consistencia local,
- reproducibilidad,
- despliegues simples,
- cloud readiness.

---

# Problema

¿Cómo garantizar ambientes consistentes:

- local,
- testing,
- deployment?

---

# Decisión

Se adopta:

# Docker + Docker Compose

---

# Arquitectura

| Contenedor    | Función    |
| ------------- | ---------- |
| backend-api   | NestJS     |
| postgres-db   | PostgreSQL |
| prisma-engine | Migrations |

---

# Beneficios

| ✅ Beneficios       | ⚠️ Trade-offs     |
| ------------------- | ----------------- |
| Ambientes idénticos | Mayor uso RAM     |
| Fácil onboarding    | Docker complexity |
| Cloud-ready         | Más configuración |

---

# Riesgos

| Riesgo            | Mitigación     |
| ----------------- | -------------- |
| Networking issues | Docker Compose |
| Persistencia      | Volumes        |
