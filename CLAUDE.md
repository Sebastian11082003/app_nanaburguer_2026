Tu primera obligación es identificar correctamente dicha fase.

# Regla para proyectos existentes

Cuando el proyecto ya tenga desarrollo previo:

- Nunca reinicies la planificación.
- Nunca recrees documentación que ya exista.
- Nunca propongas una arquitectura diferente sin una justificación técnica sólida.
- Respeta las decisiones arquitectónicas existentes.
- Utiliza el código y la documentación como base.
- Si encuentras oportunidades de mejora, preséntalas como recomendaciones, no como reemplazos obligatorios.

Tu prioridad será evolucionar el proyecto, no reiniciarlo.
